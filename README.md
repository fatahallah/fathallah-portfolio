# موقع فتح الله سيد — بورتفوليو تفاعلي (React + Tailwind)

موقع بورتفوليو تفاعلي بمكون React واحد (`src/App.jsx`)، يدعم العربية/الإنجليزية (RTL/LTR)، الوضع الداكن/الفاتح، فلترة المشاريع، نافذة تفاصيل المشروع، وعداد إحصائيات متحرك.

## 1) التشغيل محليًا

```bash
npm install
npm run dev
```

يفتح الموقع تلقائيًا على `http://localhost:5173`.

## 2) بناء نسخة الإنتاج

```bash
npm run build
```

الناتج يكون في مجلد `dist/` — جاهز للرفع على أي استضافة استاتيك.

## 3) الرفع (Deploy)

- **Vercel**: اربط المستودع على GitHub بحساب Vercel، ثم اختر Framework: **Vite**. لا حاجة لإعدادات إضافية.
- **Netlify**: Build command: `npm run build` — Publish directory: `dist`.
- **GitHub Pages**: بعد `npm run build`، ارفع محتوى `dist/` لفرع `gh-pages` (يمكن استخدام حزمة `gh-pages` أو GitHub Actions).

## 4) أين تعدّل المحتوى

كل بيانات الموقع (الاسم، المشاريع، المهارات، الخبرات، بيانات التواصل) موجودة في أعلى ملف `src/App.jsx` داخل الثوابت:

- `PROFILE` — الاسم، البريد، الهاتف، اللينكدإن، الجيت هاب، رابط السيرة الذاتية.
- `STATS` — الأرقام في قسم الـ Hero.
- `SKILL_GROUPS` — بطاقات المهارات المصنفة.
- `PROJECTS` — بطاقات المشاريع (لكل مشروع نسخة عربي وإنجليزي، تصنيف، صورة، رابط GitHub).
- `TIMELINE` — الخط الزمني للخبرات والمحطات.
- الترجمات الكاملة لواجهة الموقع موجودة في الكائن `T` (مفاتيح `en` و `ar`).

## 5) نموذج التواصل (Contact Form)

النموذج الحالي يفتح تطبيق البريد لدى الزائر برسالة جاهزة (`mailto:`) — يعمل مباشرة بدون أي إعداد خادم. إذا أردت إرسال الرسائل تلقائيًا دون فتح تطبيق بريد (عبر **EmailJS** أو **Formspree**):

1. أنشئ حسابًا مجانيًا على [EmailJS](https://www.emailjs.com) أو [Formspree](https://formspree.io).
2. استبدل محتوى دالة `handleFormSubmit` داخل `App.jsx` باستدعاء API الخاص بالخدمة (كلتاهما توفر مقتطف كود جاهز للنسخ من لوحة التحكم الخاصة بحسابك).
3. أضف مفتاح الـ API الخاص بك كمتغير بيئة (`.env`) بدلًا من كتابته مباشرة في الكود.

## 6) ملاحظة عن الصور والسيرة الذاتية

صور المشاريع موجودة في `public/projects/` والسيرة الذاتية في `public/Fathallah_Saied_CV.pdf` — استبدلها بنسخك المحدثة بنفس الأسماء، أو غيّر المسارات في `PROJECTS` و`PROFILE.cv`.
